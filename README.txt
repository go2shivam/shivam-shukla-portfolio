# Shivam Shukla — Portfolio Website

A responsive single-page portfolio website for Shivam Shukla.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — navigation and scroll animations
- `assets/profile.png` — profile image

## Free deployment
This is a static website and can be deployed on Cloudflare Pages, GitHub Pages, Netlify, or similar static hosting.

The site does not require a backend or paid server.

## Before publishing
1. Open `index.html` and check your content.
2. Replace/update the LinkedIn URL if required.
3. Add your email/GitHub later if you want them displayed.
